Operating Memory

The source of truth. Stores the current state of your businesses, systems, schedules, repositories, URLs, workflows, standing rules, and important decisions.
Use it when: something important changes. Update the canonical state so later work starts from the right facts.
Example: “Update the canonical state: Woods Run now uses loggingchance/woods-run-digest. Mark the old repo as superseded.”
OPEN OPERATING MEMORY
2

Completion Officer

Owns end-state verification. Checks whether recurring work actually finished, retries safe failures, repairs predictable problems, and escalates only real blockers.
Use it when: a scheduled or delegated workflow must complete, be checked, or be repaired.
Example: “Review tomorrow’s Woods Run cycle. Tell me whether it is properly configured and whether any repair is needed now.”
OPEN COMPLETION OFFICER
3

Production Desk · Work

Opens a new ChatGPT session with Work requested for finished deliverables. Turns rough material into completed reports, Word files, PDFs, memos, emails, presentations, spreadsheets, and client-ready outputs.
Use it when: you need the finished thing, not just research notes or drafting advice.
Example: “Turn this research into a concise client memo and a finished Word file.”
OPEN NEW WORK SESSION
4

Business Development Desk

Owns opportunity finding and qualification. Looks for grants, RFPs, contracts, prospects, reply opportunities, and other business leads actually worth your attention.
Use it when: you want a qualified opportunity queue rather than a pile of links.
Example: “Find the best current forestry-related opportunities worth pursuing this week.”
OPEN BUSINESS DEVELOPMENT DESK
5

App Factory

Owns apps and tools. Builds, audits, tests, fixes, and deploys web apps and lightweight software tools using established conventions and acceptance tests.
Use it when: an idea, formula, publication, spreadsheet, or manual process should become an app—or an existing app needs work.
Example: “Turn this calculator into a small web app and test it before deployment.”
OPEN APP FACTORY
